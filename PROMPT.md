## 4. Requisitos do Painel Administrativo (CMS Completo)

O painel administrativo deve oferecer controle absoluto ao administrador sobre:
1. **Identidade Visual e Cores**:
   - Upload e visualização do logotipo (com suporte ao arquivo oficial em `asserts/`).
   - Edição de paleta de cores global (Cor Primária/Azul Royal, Cor Secundária/Dourado, Cores de Destaque, Fundo, etc.) refletida em tempo real via CSS Variables.
2. **Textos e Títulos**:
   - Edição completa de H1, subtítulos, textos de apoio, CTAs e microcopys de todas as páginas e seções.
3. **Imagens e Mídia**:
   - Upload, seleção e alteração de imagens de produtos, banners e ilustrações técnicas.
4. **Gerenciamento de Serviços**:
   - Criação, edição, exclusão e reordenação de serviços e categorias.
5. **SEO Individual por Página**:
   - Configuração de `Meta Title`, `Meta Description`, `Keywords`, `Canonical URL`, `OG Title`, `OG Description`, `OG Image` e tags estruturadas (Schema.org / JSON-LD) para cada página individualmente.
6. **Leads e Contatos**:
   - Visualização e exportação de leads recebidos pelo formulário de contato do site (com filtros por data, bairro e tipo de problema).

## 5. Especificações Técnicas e Arquitetura

- **Frontend**:
  - React 18+ com TypeScript
  - Vite (Build rápido e otimizado)
  - Tailwind CSS + CSS Variables para customização de cores
  - Lucide React para iconografia limpa e moderna
  - React Router DOM para navegação SPA e suporte a variações de parâmetros de URL (`?h1=...`) para anúncios
- **Backend**:
  - Laravel (API RESTful)
  - MySQL Database
  - Autenticação de administradores (Laravel Sanctum)
  - Endpoints REST para:
    - `/api/settings`: Configurações globais (cores, logo, contatos, telefones, horário de funcionamento)
    - `/api/pages`: Dados de cada página e seção (textos, títulos, banners)
    - `/api/services`: Lista e detalhes de serviços
    - `/api/faqs`: Perguntas frequentes
    - `/api/seo`: Metadados e SEO individual por rota
    - `/api/leads`: Recepção e armazenamento de formulários de contato
    - `/api/admin/*`: Rotas protegidas para mutação e upload de arquivos
